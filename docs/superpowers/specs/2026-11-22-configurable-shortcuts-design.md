# Настраиваемые горячие клавиши — дизайн

Дата: 2026-11-22 · Статус: принято к реализации

## Замысел

Пользователь может переназначить существующие сочетания клавиш, отключить их и назначить
клавиши на любые действия приложения — включая запуск отчётов (встроенных и пользовательских).

## Решения

- **Единый реестр действий** (`Services/Shortcuts/`): `ShortcutCatalog` (15 статичных действий
  меню + `Search.Focus`), динамические действия приходят от источников `IShortcutActionSource`
  (`Report.Run:<templateId>` от коллекций BuiltInReports/CustomReports).
- **Логические жесты**: хранится `Primary` (→ Ctrl на Win/Linux, → ⌘ на macOS), физические
  Ctrl/Shift/Alt/Meta. Свой парсер (`GestureParser`) — `KeyGesture.Parse` кидает исключения на
  мусор и молча даёт Key.None, что неприемлемо для пользовательского ввода.
- **Хранение — отдельный файл** `%AppData%/FirebirdTraceAnalyzer/shortcuts.json`:
  ТОЛЬКО оверрайды (отсутствие записи = дефолт; `null` = осознанно отключено), `version: 1`,
  атомарная запись, порча → `.bak` + дефолты. Файл создаётся при первой смене. Сида нет
  (в отличие от rules.json — там файл источник правды, здесь — дельты). Сброс всех клавиш =
  удаление файла. Без FileSystemWatcher — применяется при старте.
- **Доставка**: attached property `Shortcut.Action` на MenuItem; applier — единственный писатель
  `InputGesture` + `HotKey` (меню показывает InputGesture, не HotKey). Смена HotKey — всегда
  null-first (иначе HotkeyManager плодит дубли KeyBinding). На macOS in-window пункты получают
  ТОЛЬКО InputGesture (отображение) — функциональный ускоритель там нативное меню, иначе ⌘-жест
  срабатывает дважды.
- **macOS**: NativeMainMenu читает реестр при построении; обновление жестов — прямая смена
  свойства Gesture у отслеженных пунктов + пересборка внутри существующего `NeedsUpdate`
  (единственная гарантированная точка синхронизации). SetMenu второй раз не вызываем.
- **Конфликты**: одинаковый разрешённый жест у двух действий → в UI блок с «Занять» (занятое
  действие становится отключённым). ⌘, — Locked (IsRebindable=false), системная конвенция macOS.
- **Осиротевшие оверрайды** (удалённый отчёт, неизвестный id) — сохраняются в файле, не
  разрешаются, чистятся только явно пользователем.
- **Плагины**: контракт не публикуем (у sort/filter-плагинов нет команд); резерв — поле `Owner`
  и внутренний `IShortcutActionSource`.
- **Экспорт/импорт settings.json** хоткеи не переносит — задокументировано.
- Локализация: только имена категорий и заголовки страниц новые (`Settings.Shortcuts.*`,
  EN+RU); текст жестов рисует платформа.

## Фазы

1. Ядро без UI: GestureSpec/Parser, Catalog, Registry, sources, ShortcutFileService + xUnit.
2. Проводка: attached property в MainMenuView.axaml, NativeMainMenu из реестра, Ctrl+F через
   `Matches`, DI, источник отчётов.
3. Страница «Горячие клавиши» в Settings: список по категориям, запись сочетания (голые
   модификаторы игнорируются, Enter — подтвердить, Esc — отмена), конфлик-баннер «Занять»,
   отключение, сбросы. Применение — немедленное (решение владельца).
4. Доки EN+RU (формат файла, `null`=отключено, `Primary`) + `shortcuts.schema.json` для
   ручных редакторов; плагинный контракт — позже, по потребности.

## Ключевые риски

- macOS double-fire (смягчён политикой applier) — проверять руками на mac перед релизом.
- Stale InputGesture, если писать HotKey без InputGesture — applier пишет оба.
- Порядок инициализации: реестр загружен ДО построения MainWindow (attached property сеет
  жесты при построении контролов) — инициализация в Program.ConfigureServices.
- «Factory reset» обязан удалять и shortcuts.json (единый оркестратор сбросов).
