# Media

Put screenshots and GIFs referenced by the docs here. Expected filenames (referenced by the
guides — rename your files to match, or update the references in `src/content/docs/`):

- `load-local.gif` — opening trace files from disk
- `load-ssh.gif` — downloading trace logs over SSH
- `explore-filter.gif` — filtering / searching events
- `reports.gif` — designing and exporting a report

Files in `public/` are served as-is (animation preserved), which is why GIFs live here rather
than in `src/assets/`.
