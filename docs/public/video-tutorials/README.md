# Стандарт медиа: видео и скриншоты

Единый каталог для демо-материалов приложения. `README.md` в корне и сайт документации
(`docs/src/content/docs/**`) ссылаются на **одни и те же файлы отсюда** — при изменении
интерфейса достаточно переснять видео/скриншот и заменить файл с тем же именем; ни README,
ни сайт править не нужно.

Файлы из каталога раздаются сайтом по пути
`/firebird-trace-analyzer/video-tutorials/<имя файла>` и видны на GitHub
по относительному пути `docs/public/video-tutorials/<имя файла>`.

## Параметры съёмки (обязательные)

| Параметр            | Значение                                          |
| ------------------- | ------------------------------------------------- |
| Окно приложения     | **1000 × 700**                                    |
| Область съёмки      | **1200 × 900**                                    |
| Отступы от краёв    | **по 100 px** слева, справа, сверху, снизу (окно строго по центру области) |
| Фон                 | светлая тема приложения → **белый** фон; тёмная тема → **чёрный** |
| Пиксели (Retina)    | допускается ровно **2×**: 2400 × 1800             |

## Формат файлов

- **Видео**: MP4, H.264, `yuv420p`, без звуковой дорожки, `+faststart`, до **60 секунд** и
  до **10 МБ** (вес репозитория + корректный рендер на GitHub и в Starlight).
- **Скриншоты**: PNG.
- GIF не используем — вместо них видео.

## Имена файлов

- Шаблон: `fta-<действие>.mp4` / `fta-<действие>.png`, kebab-case: `fta-open-local-file.mp4`.
- Вариант тёмной темы — суффикс `-dark`: `fta-open-local-file-dark.mp4`
  (имя без суффикса = светлая тема).

## Как снять (macOS)

1. Обои рабочего стола — однотонные: белый (для светлой темы) или чёрный (для тёмной).
2. Тема приложения переключается под фон съёмки (Настройки приложения).
3. Окно приложения выставить ровно **1000 × 700** и центрировать в будущей области.
4. `⌘⇧5` → «Запись выбранной области» → выделить область **1200 × 900** вокруг окна
   (по 100 px со всех сторон).
5. Остановить запись, сконвертировать в каталог:

   ```bash
   ffmpeg -i ~/Desktop/fta-open-local-file.mov \
     -c:v libx264 -crf 24 -preset medium -pix_fmt yuv420p \
     -an -movflags +faststart \
     docs/public/video-tutorials/fta-open-local-file.mp4
   ```

6. Проверить соответствие стандарту:

   ```bash
   python3 build/check-media-standard.py
   ```

## Отклонение

Несоответствующие файлы в каталог **не попадают**: скрипт проверки проверяет размер, формат
и имя и возвращает ошибку. Коммит с несоответствующим файлом не должен проходить.
