# Shared media

Theme-aware screenshots used on the documentation home page.

Put the main window screenshot here in **two versions** — the site swaps them automatically
when the theme changes (light / dark), via CSS (no JavaScript):

- `home-light.png` — shown in the **light** theme
- `home-dark.png` — shown in the **dark** theme

Use the same dimensions for both so the layout doesn't shift on theme change. Files in
`public/` are served as-is (referenced as `/<base>/shared/home-light.png`).
