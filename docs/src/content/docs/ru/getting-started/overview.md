**Firebird Trace Analyzer** — кроссплатформенное десктоп-приложение для чтения, анализа и
подготовки отчётов по трейс- и аудит-логам [Firebird](https://firebirdsql.org). Работает нативно на
**Windows, macOS и Linux**.

## Зачем

Трейс-API Firebird выдаёт плоский многословный текст, который тяжело читать и ещё тяжелее
анализировать. Приложение разбирает этот вывод в структурированные типизированные **события**,
позволяет нарезать их фильтрами и поиском и превращает результат в отчёты, которыми можно
поделиться — без написания скриптов и без загрузки всего в электронную таблицу.

## Что умеет

- **Загружает логи тремя способами** — из локальных файлов, удалённо по **SSH/SFTP** или повторно
  из локального хранилища.
- **Потоково читает и разбирает** трейс-файлы любого размера вне UI-потока, поэтому большие логи не
  подвешивают интерфейс.
- **Показывает типизированные карточки событий** для каждого типа события трассировки Firebird
  (attach/detach, начало/рестарт/завершение стейтмента, неуспешные стейтменты, процедуры, триггеры,
  ошибки и другое).
- **Фильтрует, сортирует и ищет** — мультивыбор, числовые диапазоны, диапазоны даты/времени,
  полнотекстовый поиск и стабильная сортировка по нескольким ключам.
- **По желанию сохраняет** разобранные сессии в локальном хранилище **SQLite** (WAL) с
  дедупликацией, аналитикой по размеру, read-only SQL-консолью и сжатием по требованию.
- **Строит и экспортирует отчёты** — живой конструктор с группировкой и агрегацией,
  переиспользуемые шаблоны и экспорт в **PDF, DOCX, XLSX и CSV**.
- **Расширяется** плагинами сортировки/фильтрации.
- **Темы и языки** — светлая / тёмная / авто, английский и русский.

## Для кого

Для DBA Firebird, backend-разработчиков и инженеров поддержки, которым нужно понять, что делала база
данных — медленные стейтменты, падающие запросы, всплески подключений, активность триггеров и
процедур — и передать кому-то чистый отчёт.
