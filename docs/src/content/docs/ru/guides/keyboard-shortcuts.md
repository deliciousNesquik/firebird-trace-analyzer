Ниже — значения **по умолчанию**. Любое действие, кроме открытия настроек, можно переназначить в
**Настройки → Горячие клавиши** — см. [Настройка сочетаний](#настройка-сочетаний).
В Windows и Linux используется `Ctrl`; в macOS — `⌘` (Command).

## Файлы

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Открыть локальный файл | `Ctrl+O` | `⌘O` |
| Открыть удалённый файл | `Ctrl+Shift+O` | `⌘⇧O` |
| Отменить загрузку | `Ctrl+Esc` | `⌘Esc` |
| Переразобрать все файлы | `Ctrl+R` | `⌘R` |
| Переразобрать выбранные | `Ctrl+Shift+R` | `⌘⇧R` |
| Закрыть выбранные | `Ctrl+W` | `⌘W` |
| Закрыть все | `Ctrl+Shift+W` | `⌘⇧W` |

## Раскладка

Каждое сочетание включает/выключает одну секцию. Сброс восстанавливает раскладку по умолчанию.

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Секция Files | `Ctrl+1` | `⌘1` |
| Секция Search | `Ctrl+2` | `⌘2` |
| Секция Events | `Ctrl+3` | `⌘3` |
| Секция Statistics | `Ctrl+4` | `⌘4` |
| Секция Logs | `Ctrl+5` | `⌘5` |
| Сбросить раскладку | `Ctrl+0` | `⌘0` |

## Поиск

## Отчёты

У отчётов **нет сочетаний по умолчанию** — каждый сохранённый шаблон отчёта появляется в
**Настройки → Горячие клавиши**, и ему можно назначить комбинацию для запуска одной клавишей.

## Настройка сочетаний

Откройте **Настройки → Горячие клавиши** (`Ctrl+,` / `⌘,`). Действия сгруппированы по категориям
(Файлы, Раскладка, Поиск, Приложение, Отчёты); в каждой строке — текущая комбинация и её кнопки.

### Переназначить действие

1. Нажмите **Задать** в строке.
2. Нажмите новую комбинацию — она должна содержать модификатор (`Ctrl`/`Alt`/`Shift`);
   «голые» буквы оставлены для ввода текста. **Esc** — отмена.
3. Подтвердите **Enter'ом**. Изменение применяется **сразу** — включая нативное меню macOS —
   и переживает перезапуск.

### Конфликты

Если комбинация уже занята, в строке появится **Уже назначено: …**. Нажмите **Занять**, чтобы
забрать сочетание себе — предыдущий владелец останется без него. Сочетание **Открыть настройки** —
системное: его нельзя ни занять, ни изменить.

### Отключение и сброс

- **Отключить** убирает сочетание у действия; действие остаётся доступным из меню, а вместо
  комбинации показывает `—`.
- **Вернуть по умолчанию** (в строке) восстанавливает комбинацию по умолчанию.
- **Сбросить все сочетания** удаляет `shortcuts.json` — все действия возвращаются к значениям
  по умолчанию.

### Где живут оверрайды

Хранятся только **оверрайды**: отсутствие записи означает «действует значение по умолчанию»,
явный `null` — действие отключено. Файл создаётся при первом изменении и перечитывается при
следующем запуске.

| ОС | Путь |
| --- | --- |
| Windows | `%AppData%\FirebirdTraceAnalyzer\shortcuts.json` |
| macOS | `~/Library/Application Support/FirebirdTraceAnalyzer/shortcuts.json` |
| Linux | `~/.config/FirebirdTraceAnalyzer/shortcuts.json` |

Ручное редактирование приветствуется — сверяйтесь с
[JSON-схемой](https://deliciousnesquik.github.io/firebird-trace-analyzer/shortcuts.schema.json).
Сочетания записываются как модификаторы и клавиша через `+`, где `Primary` разворачивается в
`Ctrl` (Windows/Linux) или `⌘` (macOS): `"Primary+Shift+O"`, `"Ctrl+OemComma"`, `"Primary+F5"`.
Испорченный файл или неподдерживаемая `version` бэкапятся в `shortcuts.json.bak`, действуют
значения по умолчанию. Удаление файла сбрасывает всё.
