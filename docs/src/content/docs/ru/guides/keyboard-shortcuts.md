---
title: Горячие клавиши
description: Все горячие клавиши Firebird Trace Analyzer для Windows/Linux и macOS.
---

Все сочетания по разделам. В Windows и Linux используется `Ctrl`; в macOS — `⌘` (Command).

## Файлы

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Открыть локальный файл | `Ctrl+O` | `⌘O` |
| Открыть удалённый файл | `Ctrl+Shift+O` | `⌘⇧O` |
| Отменить загрузку | `Ctrl+Esc` | `⌘Esc` |
| Переразобрать все файлы | `Ctrl+R` | `⌘R` |
| Переразобрать выбранные | `Ctrl+Shift+R` | `⌘⇧R` |
| Закрыть выбранные | `Ctrl+W` | `⌘W` |
| Закрыть все | `Ctrl+Shift+W` | `⌘⇧W` |

## Раскладка

Каждое сочетание включает/выключает одну секцию. Сброс восстанавливает раскладку по умолчанию.

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Секция Files | `Ctrl+1` | `⌘1` |
| Секция Search | `Ctrl+2` | `⌘2` |
| Секция Events | `Ctrl+3` | `⌘3` |
| Секция Statistics | `Ctrl+4` | `⌘4` |
| Секция Logs | `Ctrl+5` | `⌘5` |
| Сбросить раскладку | `Ctrl+0` | `⌘0` |

## Поиск

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Фокус в поле поиска | `Ctrl+F` | `⌘F` |
| Выполнить поиск | `Enter` | `Enter` |

## Приложение

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Открыть настройки | `Ctrl+,` | `⌘,` |
