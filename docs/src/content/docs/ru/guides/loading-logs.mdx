Вся загрузка запускается из верхнего меню **Открыть** (`Открыть [O]` — буквы в скобках это
клавиши-акселераторы):

| Пункт меню | Клавиша | Действие |
| --- | --- | --- |
| **Открыть → Локальный файл** | `L` | Выбрать трейс-файлы с диска |
| **Открыть → Удалённый файл** | `R` | Скачать трейс-файлы с сервера по SSH |
| **Открыть → Отменить загрузку** | `C` | Отменить текущую загрузку |

<Aside type="tip">
Файлы можно также **перетащить из файлового менеджера прямо в окно** — они загрузятся тем же
конвейером, что и **Открыть → Локальный файл** (дедуп по SHA-256, мгновенное переоткрытие из
хранилища). Связанные действия живут в **Правка → Перепарсить** и **Правка → Закрыть** (оба
предлагают *Все файлы* / *Выбранные файлы*).
</Aside>

## Локальные файлы

**Открыть → Локальный файл** открывает системный диалог выбора файлов.

<Steps>

1. **Выберите один или несколько файлов.** Множественный выбор разрешён — можно загрузить сразу
   целую пачку. Фильтр типов — **«Trace Logs» (`*.log`, `*.txt`)**, с запасным вариантом **«Все файлы»**.

2. **Приложение дедуплицирует.** Каждый файл считается по SHA-256; уже открытый (или уже сохранённый
   в локальном хранилище) файл переиспользуется, а не парсится повторно.

3. **Разбор идёт в фоне** с индикатором прогресса и может быть остановлен в любой момент через
   **Открыть → Отменить загрузку**.

</Steps>

## Удалённые файлы по SSH

**Открыть → Удалённый файл** открывает диалог **«Подключение к удалённому серверу»** (оверлей в окне).
Поля, помеченные `*`, обязательны. Форма разбита на карточки.

<img src={`${base}/media/load-ssh.gif`} alt="Скачивание трейс-логов по SSH" />

### Профили

Переиспользуемые подключения, сохраняемые в локальный файл профилей.

- **Загрузить сохранённый профиль** — выпадающий список показывает ваши профили (имя + хост). Выбор
  одного заполняет *все* поля ниже: хост, порт, пользователь, способ аутентификации, путь к ключу,
  удалённый каталог, флаги «после обработки» и таймаут.
- Кнопки на выбранном профиле:
  - **Открыть файл профилей** — показывает JSON профилей в файловом менеджере.
  - **Дублировать профиль** — клонирует как `<имя>_copy` (`_copy2`, `_copy3`… при совпадении).
  - **Удалить профиль** — удаляет профиль.
- **Сохранить текущие настройки как** — введите имя и нажмите **Сохранить**, чтобы сохранить текущую
  форму как профиль. Сохранение под существующим именем перезаписывает его.

<Aside type="caution" title="Секреты никогда не пишутся в файл профилей">
- **Парольная фраза ключа** не сохраняется — её вводят заново каждую сессию.
- **Пароль** восстанавливается, только если вы отметили *Запомнить пароль* — тогда он читается из
  хранилища учётных данных ОС, а не из файла профилей.
</Aside>

### Сервер

- **Имя хоста или IP-адрес `*`** — например, `192.168.1.100` или `server.example.com`.
- **Имя пользователя `*`** — учётная запись SSH, например `root`.
- **Порт `*`** — `1–65535` (по умолчанию для SSH — `22`).

### Аутентификация

Выберите один способ переключателями.

<Tabs>
  <TabItem label="Пароль">
    - **Пароль `*`** — скрыт; **Показать пароль** раскрывает его.
    - **Запомнить пароль (хранится безопасно)** — сохраняет пароль в хранилище учётных данных ОС
      (Keychain / Credential Manager / libsecret), а *не* в файле профилей. При следующей загрузке
      этого профиля пароль подставляется автоматически.
  </TabItem>
  <TabItem label="Приватный ключ">
    - **Файл приватного ключа `*`** — абсолютный путь к ключу; **Обзор…** открывает выбор файла
      (подходят `id_rsa`, `id_ed25519`, `*.pem`, …).
    - **Парольная фраза ключа (необязательно)** — скрыта; **Показать парольную фразу** раскрывает.
      Оставьте пустой для ключей без парольной фразы.

    <Aside type="tip">
    Неверная или отсутствующая парольная фраза даёт понятное сообщение
    (*«парольная фраза неверна или отсутствует…»*), а не загадочную ошибку библиотеки.
    </Aside>
  </TabItem>
</Tabs>

### Файлы трейса

- **Удалённый каталог `*`** — папка на сервере с логами, например `/var/log/firebird/trace`.

### После обработки

- **Удалить файлы с сервера** — безвозвратно удаляет трейс-файлы с удалённого хоста после того, как
  они скачаны и разобраны. При включении появляется красное предупреждение **«Это действие необратимо»**.
- **Удалить загруженные копии с этого компьютера** — при включении файлы скачиваются во временную
  папку, которая затем стирается; без него они остаются в вашей папке загрузок.

### Кнопки внизу

- **Проверить параметры** — проверяет форму на полноту/корректность **без подключения** (хост,
  пользователь, порт, путь к ключу, удалённый каталог) и сообщает результат.
- **Подключиться** — проверяет, открывает SSH-сессию (с **проверкой ключа хоста по принципу
  «доверие при первом подключении»**), убеждается, что удалённый каталог существует и читается, и
  переходит к выбору файлов. Строка статуса и индикатор прогресса показывают активность; ошибки
  выводятся в красном баннере.
- **Отмена** — закрывает диалог.

### Выбор того, что скачивать

После успешного подключения приложение перечисляет трейс-файлы в удалённом каталоге и открывает окно
**выбора файлов**:

<Steps>

1. **Найдите файлы** через поле поиска и быстрые фильтры по дате — *Сегодня / Вчера / Последние 7 дней /
   Последние 30 дней / Все файлы* — плюс **Обновить список файлов** для перечитывания каталога.

2. **Выберите файлы** через **Выбрать все / Снять выбор** или чекбоксами у каждого файла (имя, дата
   изменения и размер). Показывается счётчик **Выбрано**, а если включено *Удалить с сервера* —
   здесь тоже появляется предупреждающий баннер.

3. **Загрузить и обработать.** Подтвердите выбор — приложение скачивает файлы (окно прогресса,
   с отменой), разбирает их тем же конвейером, что и локальные, применяет ваши настройки «после
   обработки» и отключается.

</Steps>
