Вся загрузка идёт через верхнее меню **Открыть** (`Открыть [O]` — буквы в скобках это клавиши
доступа):

| Пункт меню | Клавиша | Действие |
| --- | --- | --- |
| **Открыть → Локальный файл** | `L` | Выбрать трейс-файлы на диске |
| **Открыть → Удалённый файл** | `R` | Скачать трейс-файлы с сервера по SSH |
| **Открыть → Отменить загрузку** | `C` | Отменить текущую загрузку |

<Aside type="tip">
Можно также **перетащить трейс-файлы из файлового менеджера в окно** — они загрузятся тем же
конвейером, что и **Открыть → Локальный файл** (дедупликация по SHA-256, мгновенное переоткрытие
из хранилища). Смежные действия — **Правка → Переразбор** и **Правка → Закрыть** (оба предлагают
*Все файлы* / *Выбранные файлы*).
</Aside>

## Локальные файлы

**Открыть → Локальный файл** открывает стандартный диалог выбора файлов.

<Steps>

1. **Выберите один или несколько файлов.** Допускается множественный выбор — можно загрузить
   сразу пачку. Фильтр типов файлов — **«Трейс-логи» (`*.log`, `*.txt`)**, с запасным вариантом
   **«Все файлы»**.

2. **Дедупликация.** Каждый файл снимается с отпечатком SHA-256; файл, который уже открыт
   (или уже сохранён в локальном хранилище), переиспользуется вместо повторного разбора.

3. **Разбор идёт в фоне** с индикатором прогресса; в любой момент его можно остановить через
   **Открыть → Отменить загрузку**.

</Steps>

## Удалённые файлы по SSH

**Открыть → Удалённый файл** открывает диалог **«Подключение к удалённому серверу»** (оверлей
внутри окна). Поля с `*` обязательны. Форма сгруппирована в карточки.

### Профили серверов

Многоразовые подключения, сохраняемые в локальный файл профилей (см.
[Файл профилей](#файл-профилей) ниже).

- **Загрузить сохранённый профиль** — в выпадающем списке ваши профили (имя + хост). Выбор
  заполняет все поля ниже: хост, порт, имя пользователя, метод аутентификации, путь к ключу,
  удалённый каталог, флаги «после обработки» и таймаут.
- Кнопки профиля (видны, когда профиль выбран):
  - **Открыть файл профилей** — открывает JSON профилей в файловом менеджере.
  - **Дублировать** — клонирует профиль как `<имя>_copy` (`_copy2`, `_copy3`… при коллизии).
  - **Удалить** — убирает профиль.
- **Сохранить текущие настройки как** — введите имя и нажмите **Сохранить**, чтобы сохранить
  текущую форму как профиль. Сохранение под существующим именем перезаписывает его.

### Файл профилей

Профили живут в одном JSON-файле:

| ОС | Путь |
| --- | --- |
| Windows | `%APPDATA%\FirebirdTraceAnalyzer\ssh_profiles.json` |
| macOS / Linux | `~/.config/FirebirdTraceAnalyzer/ssh_profiles.json` |

Кнопка **Открыть файл профилей** открывает этот файл в файловом менеджере. Файл — массив
профилей; один профиль выглядит так:

```json
[
  {
    "Name": "prod",
    "Settings": {
      "Hostname": "192.168.1.100",
      "Port": 22,
      "Username": "root",
      "AuthMethod": 0,
      "PrivateKeyPath": null,
      "RemoteDirectory": "/var/log/firebird/trace",
      "DeleteAfterProcessingFromServer": false,
      "DeleteAfterProcessingOnLocaleMachine": false,
      "ConnectionTimeout": 30
    },
    "CreatedAt": "2026-11-18T12:00:00",
    "LastUsedAt": "2026-11-18T12:30:00"
  }
]
```

Поля верхнего уровня:

| Поле | Тип | Значение |
| --- | --- | --- |
| `Name` | строка | Отображаемое имя профиля из выпадающего списка |
| `Settings` | объект | Настройки подключения, таблица ниже |
| `CreatedAt` / `LastUsedAt` | дата-время | Когда профиль создан / последний раз использован |

Поля `Settings`:

| Поле | Тип | Значение |
| --- | --- | --- |
| `Hostname` | строка | Адрес сервера |
| `Port` | число | `1–65535` (по умолчанию `22`) |
| `Username` | строка | Учётная запись SSH |
| `AuthMethod` | число | `0` = пароль, `1` = приватный ключ |
| `PrivateKeyPath` | строка \| null | Путь к приватному ключу (только для ключа) |
| `RemoteDirectory` | строка | Каталог с трейс-файлами |
| `DeleteAfterProcessingFromServer` | bool | Удалять файлы с сервера после обработки |
| `DeleteAfterProcessingOnLocaleMachine` | bool | Удалять скачанные копии с этого компьютера |
| `ConnectionTimeout` | число | Секунды (по умолчанию `30`) |

<Aside type="caution" title="Секреты никогда не пишутся в файл профилей">
Свойства `Password` и `KeyPassphrase` исключены из сериализации: запомненные пароли живут в
хранилище учётных данных ОС (см. ниже), парольную фразу ключа вы вводите заново каждую сессию.
</Aside>

Ручная правка безопасна при трёх правилах: JSON должен оставаться валидным, `AuthMethod` —
числовым (`0` / `1`), и приложение перечитывает файл при следующем открытии удалённого диалога.

### Учётные данные и ключи хостов

- **Запомненные пароли** хранятся в хранилище учётных данных ОС:

  | ОС | Бэкенд |
  | --- | --- |
  | Windows | DPAPI + файл в папке `Credentials` |
  | macOS | Keychain (service `FirebirdTraceAnalyzer`) |
  | Linux | Secret Service (`secret-tool`; gnome-keyring / KWallet) |

  Без запущенного keyring на Linux приложение уходит на запасной файл с правами `0600` в папке
  `Credentials` и пишет предупреждение в лог — установите `libsecret` и keyring-демон для
  полноценного хранения.

- **Ключи хостов** доверяются при первом подключении и хранятся в `known_hosts` в той же папке,
  одна строка на хост, поля через табуляцию: `host`, `port`, `keyName`, `SHA-256`-отпечаток.
  Первое подключение запоминает ключ; любой другой отпечаток или тип ключа после этого
  отклоняется, а в лог пишется возможная атака «человек посередине». Если сервер законно сменил
  ключ (переустановка, новый хост-ключ) — удалите строку этого хоста из файла и подключитесь
  заново.

### Сервер

- **Хост или IP-адрес `*`** — например, `192.168.1.100` или `server.example.com`.
- **Имя пользователя `*`** — учётная запись SSH, например `root`.
- **Порт `*`** — `1–65535` (по умолчанию `22`).

### Аутентификация

Выберите один метод переключателями.

<Tabs>
  <TabItem label="Пароль">
    - **Пароль `*`** — скрыт; **Показать пароль** раскрывает его.
    - **Запомнить пароль (сохранить безопасно)** — сохраняет пароль в хранилище учётных данных ОС
      (Keychain / Credential Manager / libsecret), а не в файл профиля. При следующей загрузке
      профиля пароль подтянется автоматически.
  </TabItem>
  <TabItem label="Приватный ключ">
    - **Файл приватного ключа `*`** — абсолютный путь к ключу; **Обзор…** открывает выбор файла
      (совпадает с `id_rsa`, `id_ed25519`, `*.pem`, …).
    - **Парольная фраза ключа (опционально)** — скрыта; **Показать passphrase** раскрывает её.
      Для ключей без фразы оставьте пустым.

    <Aside type="tip">
    Неверная или отсутствующая фраза даёт понятное сообщение
    (*«the passphrase is incorrect or missing…»*), а не криптическую ошибку библиотеки.
    </Aside>
  </TabItem>
</Tabs>

### Трейс-файлы

- **Удалённый каталог `*`** — папка на сервере с логами,
  например `/var/log/firebird/trace`.

### После обработки

- **Удалить файлы с сервера** — безвозвратно удаляет трейс-файлы с удалённого хоста после
  скачивания и разбора. При включении показывает красное предупреждение
  **«Это действие нельзя отменить»**.
- **Удалить скачанные копии с этого компьютера** — когда включено, файлы скачиваются во
  временную папку, которая очищается после обработки; когда выключено — остаются в настроенной
  папке загрузок.

### Действия в футере

- **Проверить параметры** — проверяет форму на полноту и валидность **без подключения**
  (хост, имя пользователя, порт, путь к ключу, удалённый каталог) и показывает результат.
- **Подключиться** — валидация, открытие SSH-сессии (с **trust-on-first-use проверкой ключа
  хоста**), проверка существования и читаемости удалённого каталога, затем переход к выбору
  файлов. Статусная строка и неопределённый прогресс-бар показывают активность; ошибки — в
  красном баннере.
- **Отмена** — закрывает диалог.

### Выбор файлов для скачивания

После успешного подключения приложение перечисляет трейс-файлы в удалённом каталоге и открывает
окно **выбора файлов**:

<Steps>

1. **Найдите файлы** через поле поиска и быстрые фильтры дат — *Сегодня / Вчера / Последние 7
   дней / Последние 30 дней / Все файлы* — плюс **Обновить** для перечитывания каталога.

2. **Выберите файлы** через **Выбрать все / Снять все** или флажки по файлам с именем, датой
   изменения и размером. Показывается счётчик выбранных, а при включённом *Удалить с сервера* —
   и баннер предупреждения.

3. **Скачать и разобрать.** Подтвердите выбор — приложение скачает файлы (окно прогресса с
   возможностью отмены), разберёт их тем же конвейером, что и локальные, применит выбранные
   действия «после обработки» и отключится.

</Steps>

Скачанные копии попадают в `%APPDATA%\FirebirdTraceAnalyzer\RemoteDownloads`
(`~/.config/FirebirdTraceAnalyzer/RemoteDownloads` на macOS / Linux), если не переопределить
папку загрузок в настройках. При включённом **Удалить скачанные копии с этого компьютера** эта
папка очищается после обработки.
