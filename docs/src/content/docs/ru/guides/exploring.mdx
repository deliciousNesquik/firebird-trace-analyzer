## Фильтры

Значения фильтров вычисляются из загруженных данных, поэтому вы фильтруете только по тому, что реально
встречается в ваших логах. Доступные типы фильтров:

- **Мультивыбор** — отметьте конкретные значения для включения (например, типы событий, имена
  пользователей, приложения). Сравнение строк **регистронезависимое**.
- **Числовой диапазон** — границы от/до для числовых полей (например, время исполнения, чтения/записи).
- **Диапазон даты / времени** — границы от/до по временным меткам.
- **Текстовый поиск** — поиск подстроки внутри поля.

<Aside type="tip">
Введите границу в фильтр-диапазон, и она применяется на лету. Непарсимая или некорректная по формату
граница просто игнорируется, а не ломает весь фильтр.
</Aside>

## Сортировка

Сортируйте видимые события по любому обнаруженному полю, по возрастанию или убыванию. Сортировка
**стабильна** — события, равные при сравнении, сохраняют исходный относительный порядок.

## Поиск

Полнотекстовый поиск перескакивает по загруженным событиям, чтобы быстро найти конкретный стейтмент,
таблицу или сообщение об ошибке. Поддерживает как **обычное**, так и **regex**-совпадение.

<img src={`${base}/media/search-classic-regex.gif`} alt="Обычный и regex-поиск" />

## Компоновка рабочего пространства

Меню **Окно** переключает основные панели — *Файлы*, *Поиск*, *События*, *Статистика* и *Логи* —
чтобы скрыть ненужное и отдать больше места событиям. **Окно → Сброс** восстанавливает раскладку по
умолчанию (видны все панели, кроме *Логов*).
