Есть два способа получить отчёт: **быстрые отчёты** из готовых шаблонов и **конструктор отчётов** для
сборки собственного.

## Быстрые отчёты

**Отчёты → Быстрые отчёты** перечисляет встроенные шаблоны — выберите один, и он строится из
загруженных сейчас событий, а затем экспортируется в своём формате по умолчанию.

## Конструктор отчётов

Откройте конструктор из меню **Отчёты**, чтобы собрать отчёт визуально, с **живым предпросмотром**,
который обновляется по мере ввода.

<Steps>

1. **Выберите колонки.** Добавляйте поля как колонки. У каждой колонки есть **роль**:
   - **Поле** — обычная колонка, показывающая значение как есть.
   - **Ключ группировки** — группирует строки (как `GROUP BY`).
   - **Агрегат** — вычисляемая колонка: **Count, Sum, Average, …** по каждой группе.

2. **Группировка и агрегация.** Агрегаты считаются **по группам**, поэтому агрегат даёт значение
   только когда в отчёте есть хотя бы одна колонка **Ключ группировки**.

3. **Сортировка и фильтры.** Выберите колонку для сортировки сгруппированного результата и подключите
   фильтры, чтобы отчёт включал только нужные вам события.

4. **Настройте шапку/подвал.** Задайте заголовок, подзаголовок, видимые переменные и подвал.

5. **Сохраните или экспортируйте.** Сохраните раскладку как переиспользуемый шаблон или экспортируйте
   напрямую.

</Steps>

<Aside type="caution" title="Агрегации нужен ключ группировки">
Если вы пометили колонку как агрегат, но не добавили колонку **Ключ группировки**, группировать не по
чему, поэтому агрегат не вычисляется — отчёт просто перечисляет по одной строке на событие. В таком
случае конструктор показывает встроенную подсказку.
</Aside>

## Шаблоны и история

- **Встроенные и пользовательские шаблоны** — начните со встроенного шаблона или своих сохранённых
  раскладок.
- **Управление шаблонами** — переименование, дублирование или удаление сохранённых шаблонов.
- **Недавние отчёты** — повторно открывайте отчёты, сгенерированные ранее.

## Форматы экспорта

Отчёты экспортируются в:

| Формат | Примечания |
| --- | --- |
| **PDF** | Готовый к печати документ. |
| **DOCX** | Редактируемый документ Word. |
| **XLSX** | Таблица; числовые форматы переводятся в реальные код-форматы Excel. |
| **CSV** | Чистые данные; ячейки экранируются от **инъекций формул/DDE** в таблицах. |

Экспорт идёт вне UI-потока, поэтому генерация большого отчёта не подвешивает окно и может быть отменена.
