Firebird Trace Analyzer расширяется **пользовательскими плагинами сортировки и фильтрации** — это
.NET-сборки, которые обнаруживаются и загружаются из отдельной папки плагинов при старте.

## Как это работает

- Положите сборку плагина в папку плагинов; она подхватится при следующем запуске.
- Плагины можно **включать и выключать** по отдельности. Сборка выключенного плагина даже не
  загружается, поэтому его код не исполняется.
- Если два плагина объявляют один и тот же id, приложение оставляет старшую версию, а остальные
  **затеняет**; коллизию можно разрешить, выключив ненужные.

## Модель доверия

:::danger[Плагины исполняются с полными правами]
Плагин — это .NET-сборка, которая исполняется с **полными правами приложения** — песочницы нет.
Установка плагина равнозначна запуску любой другой программы на вашей машине.
**Ставьте плагины только из источников, которым доверяете.**
:::

## Управление плагинами

На экране плагинов видно всё, что обнаружено — с именем, автором, версией и статусом
(Активен / Выключен / Затенён / Ошибка загрузки) — и можно включить или выключить каждый. Изменения
вступают в силу при следующем запуске.
