## Что он умеет

<CardGrid>
  <Card title="Загрузка откуда угодно" icon="download">
    Открывайте трейс-файлы с диска или скачивайте прямо с сервера по **SSH/SFTP** — с проверкой
    ключа хоста по принципу «доверие при первом подключении» и безопасным хранением учётных данных.
  </Card>
  <Card title="Рассчитан на большие логи" icon="rocket">
    Потоковый парсер обрабатывает файлы на миллионы событий вне UI-потока, поэтому приложение
    остаётся отзывчивым.
  </Card>
  <Card title="Просмотр и инспекция" icon="magnifier">
    Типизированные карточки событий с компактным и полным режимами, Инспектор событий,
    восстанавливающий весь жизненный цикл соединения вокруг любого события.
  </Card>
  <Card title="Фильтры и поиск" icon="setting">
    Фильтры (мультивыбор / диапазон / текст), стабильная сортировка и полнотекстовый поиск
    по миллионам событий.
  </Card>
  <Card title="Отчёты и экспорт" icon="document">
    Живой конструктор отчётов с группировкой и агрегацией, переиспользуемые шаблоны и экспорт
    в один клик в PDF / DOCX / XLSX / CSV.
  </Card>
  <Card title="Диагностика и расширение" icon="wrench">
    Статистика парсера с таймингами по фазам конвейера; плагины сортировки и фильтрации
    через SDK.
  </Card>
</CardGrid>
