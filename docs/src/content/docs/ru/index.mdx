## Возможности

<CardGrid>
  <Card title="С диска или по SSH" icon="download">
    Открывайте файлы с диска или скачивайте их с сервера по SSH/SFTP. Ключи хоста — по схеме
    доверия при первом использовании (TOFU), учётные данные — в системном хранилище.
  </Card>
  <Card title="Потоковый парсер" icon="rocket">
    Парсер обрабатывает файлы на миллионы событий в потоковом режиме, вне UI-потока, поэтому
    интерфейс не блокируется.
  </Card>
  <Card title="Карточки событий" icon="magnifier">
    У каждого типа события своя карточка; список переключается между компактным и полным
    видом. Инспектор событий восстанавливает жизненный цикл соединения по выбранному событию.
  </Card>
  <Card title="Фильтры и поиск" icon="list-format">
    Мультивыбор, диапазоны и текстовые фильтры, стабильная сортировка, полнотекстовый поиск.
  </Card>
  <Card title="Конструктор отчётов" icon="document">
    Группировка, агрегация, переиспользуемые шаблоны; экспорт в PDF / DOCX / XLSX / CSV.
  </Card>
  <Card title="Статистика и плагины" icon="analytics">
    Статистика парсера с таймингами по этапам обработки; плагины сортировки и фильтрации
    через SDK.
  </Card>
</CardGrid>
