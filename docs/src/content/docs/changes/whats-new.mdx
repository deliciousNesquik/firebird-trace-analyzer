Release notes, newest first. Versions follow the project's git tags; minor releases are described in
detail, patch releases summarized.

## 1.15.0 — August 28, 2026

Error-chain filtering, a split of developer mode, redesigned toolbar buttons, and a new app icon.

- **Filtering:** filter events by fields inside the error chain — **Error Code** and **Error Message**.
  They live inside a collection on error events and were previously unreachable; an event now matches
  when any line in its error chain matches. They appear once the view is narrowed to error events.
- **Diagnostic tools:** the single *Developer mode* is now two independent switches — **Parser
  Statistics** and **Event Inspector**. The per-event inspector button shows only when *Event
  Inspector* is enabled; its unreliable right-click menu entry was removed.
- **Toolbar:** redesigned search / sort / filter buttons — the filter button carries a badge with the
  number of active filters, the search button an activity badge; unified button styling.
- **App icon:** a new application icon.
- **Fixes:** the error-card copy button, the settings-window icon color, the plugins view (icon color;
  the collisions section is hidden when empty), the events empty-state visibility, and more accurate
  human-readable byte sizes.

## 1.14.0 — August 13, 2026

Drag-and-drop file loading.

- Drag trace files (`.log`, `.txt`) from your file manager and drop them onto the window — they load
  through the same pipeline as **Open → Local File** (SHA-256 de-duplication, instant re-open from the
  store). A hint appears while dragging; non-trace files (images, archives, …) are ignored.

## 1.13.0 — August 13, 2026

Localization fixes, a Window → Reset fix, and an SDK and documentation update.

- **Localization:** the filter three-state checkbox tooltip and the download-window title are now
  localized (they were previously hardcoded).
- **Window → Reset** restores the default layout again — every panel except *Logs* (it previously
  had no effect).
- **SDK:** a shorter `FilterDescriptor` constructor for predicate-only filters (no `propertyPath`),
  and documented runtime-tunable plugin filters.
- **Documentation:** a full documentation site (English + Russian) covering the app and the plugin SDK.

## 1.12.0 — July 23, 2026

A broad core-and-app review focused on security, performance and reliability, plus a large internal
architecture cleanup.

- **Security:** SSH host-key verification (trust-on-first-use via `known_hosts`) against
  man-in-the-middle; passwords and key passphrases are never written to SSH profiles; the fallback
  credential store is encrypted with AES-256-GCM; path-traversal protection for downloaded filenames
  and report-template ids; the macOS keychain password is passed via stdin rather than the command line.
- **Performance:** trace parsing runs off the UI thread; filter predicates are compiled once per pass
  and sort keys extracted once per event; faster PDF and XLSX export; parser hot-path optimizations
  (regex caching, fewer allocations); removed an N+1 in the event store.
- **Reliability:** global crash handlers route background failures to the log instead of failing
  silently; the filter pipeline runs on a snapshot (fixes a race when loading or closing files);
  OOM protection on malformed logs via a block-size cap.
- **Under the hood:** the main view-model was split into focused, dependency-injected services,
  `IEventStore` was split by role, event cards share common base classes, and a new parser test suite
  was added.

## 1.11.0 — July 17, 2026

Event-store analytics and maintenance: a read-only SQL console and disk-space compaction.

- **Storage analysis:** a read-only SQL console over the event store — SQL syntax highlighting,
  autocomplete (keywords, schema, table/alias columns, table list after `FROM`/`JOIN`), a searchable
  schema-cards view, and editor font zoom (`Ctrl`+wheel, `Ctrl` +/-/0).
- **Storage maintenance:** **Compact** reclaims disk space (`VACUUM` + orphan cleanup) and also runs
  automatically in the background on the next launch after deletions; confirmation prompts before
  deleting selected files or clearing the whole store.
- **Filtering:** filters and sorts are computed in the background with a loading indicator.
- **Parser:** performance tables are parsed correctly, including for procedures and triggers.
- **UI:** modernized storage window; fixed the event-card grid.

## 1.10.1 — July 13, 2026

A security and remote-connection patch.

- **Security:** the password is kept in the OS credential store (Secret Service / `secret-tool` on
  Linux) and is no longer retained in memory after connecting; updated SQLitePCLRaw to 3.0.3
  (fixes GHSA-2m69-gcr7-jv3q).
- **Remote:** faster SFTP downloads (256 KB buffer, throttled progress) and cleaner resource release
  on disconnect.

## 1.10.0 — July 13, 2026

The optional local event store, new filter types, and a substantial speed-up.

- **Local event store (SQLite/WAL):** persist parsed sessions and re-open them instantly instead of
  re-parsing; a storage-mode setting; a session-recovery dialog on startup.
- **Storage management:** statistics, a database size breakdown, export/import between machines, and
  "load to session" from the store.
- **Filters:** a "contains" text filter (`TextSearch`) in the panel and the report designer;
  boolean-field filters; SQL treated as a text filter.
- **Performance:** an integer `file_id` instead of a file hash plus index cleanup (large
  database-size reduction), a background write queue (disk off the parse critical path), and
  SQL-text memoization (removed an N+1).
- **Diagnostics:** parser statistics by phase, with a developer mode.
- **UI:** a reusable background-task indicator with store-write status; select remote files by
  clicking the card.
- **Fixes:** filenames removed from the PDF title; corrected built-in report column widths; fixed the
  default-sort flag.

## 1.0.0 — June 18, 2026

The first release — a cross-platform desktop app that turns Firebird trace and audit logs into
structured, typed events.

- Streams and parses trace files of any size off the UI thread.
- Loads logs from local files or remotely over SSH/SFTP.
- Typed event cards for every trace event type.
- Multi-select, numeric/date-range and text filters, stable multi-key sorting, and full-text search.
- A report designer with the same filters as the main view, and export to PDF, DOCX, XLSX and CSV.
