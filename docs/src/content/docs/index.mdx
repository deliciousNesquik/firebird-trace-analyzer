## What it does

<CardGrid>
  <Card title="Open from disk or over SSH" icon="download">
    Open files from disk, or download them from a server over SSH/SFTP. Host key verification
    is trust-on-first-use; credentials are stored in the OS credential store.
  </Card>
  <Card title="Streaming parser" icon="rocket">
    The parser handles multi-million-event files in a streaming pass, off the UI thread;
    the interface stays responsive.
  </Card>
  <Card title="Typed event cards" icon="magnifier">
    Each event type has its own card, in Compact or Full list layouts. Select an event and
    the Event Inspector reconstructs the full lifecycle of its connection.
  </Card>
  <Card title="Filtering and search" icon="list-format">
    Multi-select, range and text filters, stable sorting, full-text search.
  </Card>
  <Card title="Report designer" icon="document">
    Design reports with grouping and aggregation, save them as templates, export to
    PDF / DOCX / XLSX / CSV.
  </Card>
  <Card title="Statistics and plugins" icon="analytics">
    Parser statistics with per-phase pipeline timings; sort and filter plugins through the SDK.
  </Card>
</CardGrid>
