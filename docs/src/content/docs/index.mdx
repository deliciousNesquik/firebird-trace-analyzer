## What it does

<CardGrid>
  <Card title="Load from anywhere" icon="download">
    Open trace files from disk, or pull them straight off a server over **SSH/SFTP** — with
    trust-on-first-use host-key verification and secure credential storage.
  </Card>
  <Card title="Built for big logs" icon="rocket">
    A streaming parser processes multi-million-event files off the UI thread, so the app
    stays responsive.
  </Card>
  <Card title="Explore & inspect" icon="magnifier">
    Typed event cards with Compact/Full layouts, and an Event Inspector that rebuilds a
    connection's whole lifecycle around any event.
  </Card>
  <Card title="Filter & search" icon="setting">
    Multi-select, range and text filters, stable sorting and full-text search across
    millions of events.
  </Card>
  <Card title="Report & export" icon="document">
    A live report designer with grouping and aggregation, reusable templates and one-click
    export to PDF / DOCX / XLSX / CSV.
  </Card>
  <Card title="Diagnose & extend" icon="wrench">
    Parser statistics with per-phase pipeline timings; sort and filter plugins through the
    plugin SDK.
  </Card>
</CardGrid>
